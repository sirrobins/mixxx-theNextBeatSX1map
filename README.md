# mixxx-theNextBeatSX1map
A new SX1 dj controller map for Mixx. (midi-components.js)


Usage:

0. Locate your personal controllers map directory in Mixxx.
Additional info about controllers directory location:
https://github.com/mixxxdj/mixxx/wiki/controller%20mapping%20file%20locations

1. Download below 2 files, and place in your user "controllers" directory.
TheNextBeat-SX1.midi.xml
TheNextBeat-SX1.scripts.js

2. Restart Mixxx and go to Preferences > Controllers.
Choose The Next Beat SX1.
On Controller setup tab, load mapping, choose: TNB-SX1 Mixxx

3. Push Apply and OK.
